# Generated method scripts

One executable per Platform API method, generated by `../tools/gen-scripts.py` from the vendor's
live OpenAPI document (422 at spec 8.15). Do not edit by hand - regenerate.

```bash
VZ_HOST=app.<your-platform-domain> VZ_TOKEN=*** ./scripts/environment/control/getenvs.sh
./scripts/environment/control/getenvinfo.sh envName=my-env
./scripts/environment/control/getenvinfo.sh envName=my-env --dry-run   # print, don't send
./scripts/environment/control/stopenv.sh envName=my-env                # refused: write class
```

Read/write classification matches the verb guard in `../tools/vz-api.sh`: read-shaped
(`get*/check*/is*/find*/list*`) run freely; everything else stops unless `VZ_ALLOW_DESTRUCTIVE=1`.
`scripts/index.tsv` is the whole catalogue in one file (`path  class  required`).
Consistency of this tree with `../data/api-catalog.json` is enforced by
`python3 tools/gen-scripts.py --check` (runs in CI).
